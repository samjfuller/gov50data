# `{gov50data}` Datasets for Data Science in the Social Sciences
## (Cloned from [Matt Blackwell](https://github.com/mattblackwell))


To install the Gov 50 data package run the following command:

``` r
pak::pak("mattblackwell/gov50data")
```


To load a dataset:

``` r
library(gov50data)
data(news)
```
